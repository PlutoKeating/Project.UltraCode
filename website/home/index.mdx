## 无侵入增强

UltraCode 不替换 OpenCode，不修改 Provider 或模型，也不读取任何凭据。安装器只添加角色、工作流、长跑和视觉 QA，并保留用户已有配置。

```bash
curl -fsSL https://project-ultracode.williamhvollita.workers.dev/install.sh | bash
```

- Provider 与 Model 完全中立
- 幂等应用与最大并集合并
- 官方 OpenCode 升级保持可用
- 发布制品 SHA-256 与来源证明
