## Выбор между двумя основными ролями

Нажмите `Shift+Tab` внутри OpenCode в любой момент для переключения:

| Основная роль | Режим | Что делает | Когда использовать |
| --- | --- | --- | --- |
| **`UltraBuild`** | По умолчанию | Уточняет цели, планирует этапы, координирует специалистов и доводит задачу до рабочего результата | Повседневная разработка, исправление ошибок и поставка фич под ключ |
| **`UltraPlan`** | `Shift+Tab` | Строго безопасное планирование только для чтения — никогда не меняет ваш код | Проработка ранних идей, технических компромиссов и архитектуры без риска |

## Что автоматически делают 5 фоновых экспертов

Вызывать их вручную не нужно — `UltraBuild` сам подключает каждого специалиста в нужный момент:

- **Исследование**: изучает соглашения вашего проекта и внешнюю документацию, чтобы решения опирались на факты, а не на догадки.
- **Архитектура**: проектирует потоки данных, границы модулей и компромиссы до написания кода.
- **Реализация**: пишет чистые, точно ограниченные изменения вместе с соответствующими тестами.
- **Критическое код-ревью**: независимо проверяет diff на граничные случаи, регрессии и упущенные требования.
- **Визуальная проверка в реальном браузере**: запускает настоящий браузер, проходит пользовательские сценарии и проверяет скриншоты для десктопа и мобильных устройств.
