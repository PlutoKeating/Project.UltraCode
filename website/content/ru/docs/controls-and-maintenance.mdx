Повседневное управление едино для терминала, настольного приложения и мобильного/веб-интерфейса — настройки синхронизируются в реальном времени без ручного редактирования конфигов.

## Переключатели в любом интерфейсе

- **Настольное приложение (OpenCode Desktop)**: нажмите плашку **UltraCode** над полем ввода для переключения в один клик или откройте **Settings → UltraCode**.
- **Терминал (TUI)**: откройте палитру команд и найдите **UltraCode**.
- **Веб и смартфон (`ultracode pair`)**: введите `/approvals` или `/direction` в поле ввода (меню `/` показывает актуальный статус `auto` / `manual` и переключает его мгновенно без вызова ИИ-модели).

- **Одобрение команд (`/approvals`)**: включён (`auto`) по умолчанию, чтобы рутинные операции выполнялись без постоянных запросов, при этом ваши явные запрещающие правила всегда остаются в силе.
- **Вопросы по направлению (`/direction`)**: включён (`manual`) по умолчанию, чтобы на серьёзных продуктовых или архитектурных развилках UltraCode запрашивал ваше решение через карточки выбора.

## Единый справочник команд

| Команда | Что делает |
| --- | --- |
| `ultracode` | Открывает терминальный интерфейс (все флаги и подкоманды OpenCode работают напрямую) |
| `ultracode desktop` | Запускает OpenCode Desktop или скачивает официальный установщик, если приложение ещё не установлено |
| `ultracode pair` | Показывает ссылку и QR-код привязки для доступа из браузера или со смартфона |
| `ultracode upgrade` | Обновляет официальный OpenCode и UltraCode вместе, после чего выполняет синхронизацию |
| `ultracode sync` | Повторно выравнивает конфигурацию и управляемую среду выполнения |
| `ultracode doctor` | Быстрая проверка исправности окружения без единого вызова ИИ-модели |
| `ultracode uninstall --yes` | Чисто удаляет UltraCode, сохраняя ваши собственные конфиги и резервные копии |
