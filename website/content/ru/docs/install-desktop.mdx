Рекомендуется большинству: **сначала установите UltraCode, затем добавьте настольное окно.** Скопируйте строку для своего компьютера и вставьте её в терминал (в Windows — PowerShell).

## <span class="uc-step-no">01</span> Установите UltraCode

<CommandBlock
  title="macOS / Linux"
  command="curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash"
  copyLabel="Копировать"
  copiedLabel="Скопировано"
/>

<CommandBlock
  title="Windows"
  command="irm https://ultracode.plutokeating.beer/install.ps1 | iex"
  copyLabel="Копировать"
  copiedLabel="Скопировано"
/>

Оба блока делают одно и то же: подготавливают официальный OpenCode, бинарник UltraCode и нужную среду выполнения. Заранее устанавливать больше ничего не нужно. Если после этого текущее окно не находит `ultracode`, закройте и снова откройте терминал перед следующим шагом.

**Что вы увидите:** обновление OpenCode, установку UltraCode, завершение настройки и в конце — версию и Ready.

## <span class="uc-step-no">02</span> Добавьте настольное окно

<CommandBlock
  label="Введите это в терминале"
  command="ultracode desktop"
  copyLabel="Копировать"
  copiedLabel="Скопировано"
/>

При первом запуске скачивается официальный установщик для десктопа: в macOS и Windows открывается системное окно установки, где нужно нажать несколько раз «Далее»; в Linux установщик открывается сразу. После этого приложение можно запускать и из обычного списка программ.

**Что вы увидите:** настольное приложение открывается; в первый раз оно скачивает официальный установщик для вашей системы, а дальше просто запускается.

Установили? Начните с [практики на десктопе](/ru/docs/tutorial-desktop/). Нужен только терминал, без настольного окна? Смотрите [установку только терминала](/ru/docs/install-terminal/).
