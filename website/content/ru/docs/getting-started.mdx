Предварительная настройка не нужна — если официальный **OpenCode V2** (включая актуальные выпуски `v2.4+`) ещё не установлен, установщик автоматически поставит или обновит его.

## Шаг 1: Установка одной строкой

**macOS / Linux**:

```bash
curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash
```

**Windows (PowerShell)**:

```powershell
irm https://ultracode.plutokeating.beer/install.ps1 | iex
```

После установки для всех сценариев достаточно одной команды — `ultracode`:

```bash
ultracode           # Открыть терминальный интерфейс
ultracode desktop   # Запустить или установить официальное приложение OpenCode Desktop
ultracode pair      # Подключить браузер или смартфон по ссылке / QR-коду
```

## Шаг 2: Почувствуйте разницу в работе

Откройте пустую папку, запустите `ultracode` (или `OpenCode Desktop`) и отправьте одно предложение:

> Сделай минималистичную страницу бронирования столика для локальной кофейни: выбор даты, времени и числа гостей, а после отправки — карточка подтверждения. Убедись, что вёрстка на десктопе и мобильном выглядит аккуратно и без наложений.

Обратите внимание, чем это отличается от обычного ИИ-чата:

1. **Сразу уточняет детали карточками выбора**: вместо слепых догадок UltraCode собирает ключевые вопросы по стилю и объёму задачи в быстрые варианты ответа.
2. **Планирует, пишет код и проводит ревью в фоне**: профильные роли координируются за кулисами, пока ваша сессия сфокусирована на этапах и результате.
3. **Проверяет собственный интерфейс в реальном браузере Chromium**: сам прокликивает элементы управления, сверяет скриншоты десктопной и мобильной версий и исправляет дефекты вёрстки до завершения работы.
