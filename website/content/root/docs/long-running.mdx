## 你在长程任务中的真实体验

- **自动稳步推进**：每个里程碑完成后自动进入下一阶段，聊天界面只保留里程碑进展、阻塞点与验收结论。
- **随时插话即刻生效**：你在任意时刻发出的新消息都会立即改变方向或暂停执行，控制权始终在你手里。
- **重启或隔天无缝续跑**：哪怕关掉终端、换了一天，重新打开 `opencode` 只需说一句：

```text
读取交接并继续
```

UltraCode 会自动找回上次的进度、已完成的验收与下一步计划，接着把剩下的事情做完。
