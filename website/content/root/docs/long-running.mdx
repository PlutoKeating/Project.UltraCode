## How Long-Running Work Works in Practice

- **Steady, evidence-gated progress**: Start directly in natural chat or run `/goal <your objective>` — UltraCode clarifies open decisions upfront, advances across milestones automatically, and checks every requirement before declaring work complete.
- **Instant pause, resume, or steering at any time**: Send a new message, use `/goal pause` and `/goal resume`, or click **Pause / Resume / Clear** in the **UltraCode** pill. Run `/review` anytime for an independent audit.
- **Clean resumption across sessions**: Close your terminal or desktop app and come back later — simply run `ultracode` and say:

```text
Read the handoff and continue
```

UltraCode restores the saved progress, verified evidence, and next planned step directly from your repository.
