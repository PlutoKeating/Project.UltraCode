Terminal mode is the most direct surface: **it works only inside the folder you opened it in.**

<TutorialStep
  step={1}
  title="Install with one line"
  promptLabel="On macOS / Linux, copy this"
  promptText="curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash"
  isCommand={true}
  copyLabel="Copy"
  copiedLabel="Copied"
  expectLabel="What you'll see"
  expectText="It updates OpenCode, installs UltraCode, finishes setup, and ends with the version plus Ready."
>
  On Windows use PowerShell: `irm https://ultracode.plutokeating.beer/install.ps1 | iex`. If the current window cannot find the command afterwards, close and reopen the terminal.

<TutorialStep

  To work somewhere else, run it again inside that folder. It never touches anything outside it.
</TutorialStep>

</TutorialStep>
