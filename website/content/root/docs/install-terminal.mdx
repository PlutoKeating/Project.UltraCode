If all you want is the terminal interface: **install it once and use it inside any folder**, with no desktop window. Copy the line for your computer and paste it into a terminal (PowerShell on Windows).

## <span class="uc-step-no">01</span> Install with one line

<CommandBlock
  title="macOS / Linux"
  command="curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash"
  copyLabel="Copy"
  copiedLabel="Copied"
/>

<CommandBlock
  title="Windows"
  command="irm https://ultracode.plutokeating.beer/install.ps1 | iex"
  copyLabel="Copy"
  copiedLabel="Copied"
/>

Both boxes do the same thing. If the current window cannot find `ultracode` afterwards, close and reopen the terminal.

**What you'll see:** it updates OpenCode, installs UltraCode, finishes setup, and ends with the version plus Ready.

## <span class="uc-step-no">02</span> Open it inside the folder you want to work on

<CommandBlock
  label="Enter the folder first, then run"
  command="ultracode"
  copyLabel="Copy"
  copiedLabel="Copied"
/>

To work somewhere else, run it again inside that folder. It never touches anything outside it.

**What you'll see:** a prompt appears in the middle and the current folder name sits along the bottom.

## <span class="uc-step-no">03</span> Confirm it sees your folder

Wrong path means you opened it somewhere else — exit and reopen in the right place.

**What you'll see:** the path at the bottom matches the folder you meant, with UltraCode on the right.

Installed? Continue with [Terminal mode without fear](/docs/tutorial-terminal/). Want the desktop window later? Run `ultracode desktop` whenever you like — no reinstall needed.
