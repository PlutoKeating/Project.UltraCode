## Four Checks Before Calling UI Work Done

1. **Launches your real app**: Starts the local server and opens it in a real Chromium browser.
2. **Interacts like a real user**: Clicks buttons, fills forms, and navigates flows to catch console or runtime errors.
3. **Inspects desktop & mobile viewports**: Checks for overlapping elements, clipped text, alignment issues, and contrast problems across screen sizes.
4. **Fixes and re-verifies**: Whenever a visual or interaction defect is found, UltraCode fixes it and re-checks before delivering.
