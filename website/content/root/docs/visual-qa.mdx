## 交付前自动完成的四道目视关卡

1. **启动真实页面**：自动运行开发服务，在无头真实浏览器中打开你的应用。
2. **模拟真实用户操作**：逐项点击按钮、填写表单、切换状态，确认交互链路畅通无报错。
3. **双端截屏巡检**：同时检查桌面端与移动端画面，捕捉文字遮挡、元素溢出、对齐失衡与暗亮色对比度瑕疵。
4. **发现即修再复验**：只要画面或交互不达标，自动回炉修复并重新截屏确认，不会把半成品交给你。
