## Describe What You Want in Plain Language

No special slash commands or prompt templates required. Simply state three things clearly:

- **Who it is for**: the target audience and where it runs (desktop, mobile, terminal, API).
- **What it should do**: core behavior, style preferences, and anything explicitly out of scope.
- **How to verify it**: your real acceptance bar (passing tests, clean mobile layout, reliable edge cases).
