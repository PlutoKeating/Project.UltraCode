## 1. Does UltraCode modify official OpenCode or read my API keys?

**No.** UltraCode is strictly additive and provider/model-neutral. It never patches the official OpenCode CLI or Desktop binary, and never reads, stores, or transmits your API keys.

## 2. Do I need to install OpenCode before installing UltraCode?

**No.** On macOS, Linux, and Windows, both the install script and `ultracode upgrade` automatically detect official OpenCode V2, installing it from the official channel if missing or keeping it updated.

## 3. Which AI models does UltraCode support?

**Whatever model and provider you already configure in OpenCode.** UltraCode never locks you into a single model vendor.

## 4. Will UltraCode overwrite my existing OpenCode configuration or skills?

**No.** Install and sync merge additively while preserving your existing settings, comments, and skills. Running `ultracode uninstall --yes` removes only unmodified files added by UltraCode.

## 5. How do I update UltraCode or verify setup health?

Run `ultracode upgrade` to update official OpenCode and UltraCode together, or run `ultracode doctor` anytime for a fast check that makes **zero AI model calls**.
