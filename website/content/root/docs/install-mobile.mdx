Nothing needs to be installed on the phone: **it borrows the workbench on your computer.**

## <span class="uc-step-no">01</span> Make sure UltraCode is installed on the computer

<CommandBlock
  label="Type this in the computer terminal"
  command="ultracode pair"
  copyLabel="Copy"
  copiedLabel="Copied"
/>

If UltraCode is not installed on this computer yet, do [the terminal + desktop install](/docs/install-desktop/) first, then come back.

**What you'll see:** one link appears that you can open directly. It stays valid for a few minutes only.

## <span class="uc-step-no">02</span> Send the link to your phone and open it

A chat app, a note, or email to yourself all work; some terminals also show a QR code you can scan.

**What you'll see:** the same interface in your phone browser, with the same project list as the computer.

## <span class="uc-step-no">03</span> Tap, interrupt, and continue on the phone

<CommandBlock
  label="Commands work in the phone composer too"
  command="/direction"
  copyLabel="Copy"
  copiedLabel="Copied"
/>

The other switch is `/approvals`, which controls whether it asks before running an action. Both stay in sync between computer and phone.

**What you'll see:** the questioning mode switches immediately and the computer display follows.

Connected? Continue with [Phone remote control](/docs/tutorial-mobile/).
