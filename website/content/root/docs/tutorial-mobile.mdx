This lesson solves something very practical: **the work has started, but you have to leave the desk.**

You do not need remote desktop, and you do not need to carry the laptop. A phone browser can take over the same progress.

<TutorialStep
  step={1}
  title="Create a pairing link on the computer"
  promptLabel="Type this in the terminal — the only line you need"
  promptText="ultracode pair"

  copyLabel="Copy"
  copiedLabel="Copied"
  expectLabel="What you'll see"
  expectText="One link appears that you can open directly. It stays valid for a few minutes only."
>
  Copy that link and send it to yourself in a phone chat window — the most reliable way to move it across.
</TutorialStep>

  step={3}
  title="Answer its questions right on the phone"

</TutorialStep>
