The terminal sounds intimidating, but there is really only one thing in front of you: **a box you can type into.**

In this lesson we use it to turn a messy folder of meeting notes into a clear to-do list.

<TutorialStep
  step={1}
  title="Open it and look at the “black window” once"
  expectLabel="What you'll see"
  expectText="A prompt in the middle, your current folder name along the bottom, and the UltraCode label to the right. The blinking cursor is simply waiting for you to speak."
>
  Open it inside the folder you want to work on. The lines around the edges are just frames — there is nothing you need to type as a command.

</TutorialStep>

<TutorialStep
  step={2}
  title="State the outcome in one sentence"
  promptLabel="Send this sentence"
  promptText="Turn the meeting notes in this folder into a clear action list: group by owner, say what to do and when it is due, and save it as a new file without deleting the originals."
  copyLabel="Copy"
  copiedLabel="Copied"
  expectLabel="What you'll see"
  expectText="It looks through the folder first, tells you how it plans to organise things, and only then starts working."
>
  The important half is the ending: **say which files may change and which must stay untouched.** That is what makes it safe to let it act.
</TutorialStep>

<TutorialStep
  step={3}
  title="When you need one more action, open the slash menu"
  expectLabel="What you'll see"
  expectText="A list of clickable commands appears in the middle — switch model, open settings, and so on. Move with the arrow keys and press Enter."
>
  See `ctrl+p commands` at the bottom? That is the command menu. You never have to memorise a command; open the menu and pick.

<TutorialStep
  step={4}
  title="Keep talking instead of starting over"
  promptLabel="Adjust it like this"
  promptText="Tighten the list: only what is still open this week, sorted by the nearest due date."
  copyLabel="Copy"
  copiedLabel="Copied"
  expectLabel="What you'll see"
  expectText="Only this list changes; the notes it already organised are not rebuilt from scratch."
>
  Terminal mode and the desktop app are the same capability in a different window. Use whichever feels natural.
</TutorialStep>
