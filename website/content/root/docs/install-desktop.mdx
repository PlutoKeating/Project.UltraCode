Recommended for most people: **install UltraCode first, then add the desktop window.** The only difference between platforms is one line of command — copy the box that matches your computer.

<TutorialStep
  step={1}
  title="Install UltraCode"
  expectLabel="What you'll see"
  expectText="It updates OpenCode, installs UltraCode, finishes setup, and ends with the version plus Ready."
>
  <InstallCommands
    unixLabel="macOS / Linux"
    windowsLabel="Windows"
    unixHint="Paste it in Terminal"
    windowsHint="Paste it in PowerShell"
    unixCommand="curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash"
    windowsCommand="irm https://ultracode.plutokeating.beer/install.ps1 | iex"
    copyLabel="Copy"
    copiedLabel="Copied"
  />

  Both boxes do the same thing: they prepare official OpenCode, the UltraCode binary, and the runtime it needs. Nothing else has to be installed first. If the current window cannot find `ultracode` afterwards, close and reopen the terminal before the next step.
</TutorialStep>

<TutorialStep
  step={2}
  title="Add the desktop window"
  promptLabel="Type this in the terminal"
  promptText="ultracode desktop"
  isCommand={true}
  copyLabel="Copy"
  copiedLabel="Copied"
  expectLabel="What you'll see"
  expectText="The desktop app opens; the first time it downloads the official installer for your system, after that it just launches."
>
  On the first run it downloads the official desktop installer: macOS and Windows open a system installer window you click through; Linux opens it directly. Afterwards you can also launch it from your normal app list.
</TutorialStep>
