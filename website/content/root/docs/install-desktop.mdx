Recommended for most people: **install UltraCode first, then add the desktop window.** Copy the line for your computer and paste it into a terminal (PowerShell on Windows).

## <span class="uc-step-no">01</span> Install UltraCode

<CommandBlock
  title="macOS / Linux"
  command="curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash"
  copyLabel="Copy"
  copiedLabel="Copied"
/>

<CommandBlock
  title="Windows"
  command="irm https://ultracode.plutokeating.beer/install.ps1 | iex"
  copyLabel="Copy"
  copiedLabel="Copied"
/>

Both boxes do the same thing: they prepare official OpenCode, the UltraCode binary, and the runtime it needs. Nothing else has to be installed first. If the current window cannot find `ultracode` afterwards, close and reopen the terminal before the next step.

**What you'll see:** it updates OpenCode, installs UltraCode, finishes setup, and ends with the version plus Ready.

## <span class="uc-step-no">02</span> Add the desktop window

<CommandBlock
  label="Type this in the terminal"
  command="ultracode desktop"
  copyLabel="Copy"
  copiedLabel="Copied"
/>

On the first run it downloads the official desktop installer: macOS and Windows open a system installer window you click through; Linux opens it directly. Afterwards you can also launch it from your normal app list.

**What you'll see:** the desktop app opens; the first time it downloads the official installer for your system, after that it just launches.

Installed? Start with [the desktop walkthrough](/docs/tutorial-desktop/). Want the terminal only, no desktop window? See [terminal-only install](/docs/install-terminal/).
