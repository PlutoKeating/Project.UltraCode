## Choosing Between the Two Primary Roles

Press `Shift+Tab` inside OpenCode at any time to switch:

| Primary Role | Default | What It Does | Best For |
| --- | --- | --- | --- |
| **`UltraBuild`** | Default | Clarifies goals, plans milestones, coordinates specialists, and ships verified results | Everyday building, bug fixing, and end-to-end delivery |
| **`UltraPlan`** | `Shift+Tab` | Strictly read-only planning — never modifies your code | Exploring architecture, scope, and trade-offs safely |

## What the 5 Background Specialists Do Automatically

You never need to invoke them manually — `UltraBuild` dispatches each specialist when useful:

- **Librarian**: Reads official docs, repository conventions, and open-source prior art before implementation.
- **Architect**: Analyzes module boundaries, root causes, and design trade-offs.
- **Implementer**: Delivers bounded code changes together with project-native verification.
- **Reviewer**: Audits diffs independently for regressions, security issues, and missed requirements.
- **Visual Evaluator**: Opens a real browser to exercise interactive flows and inspect desktop and mobile layouts.
