Day-to-day control stays synchronized across Terminal, Desktop, and Web/Mobile in real time with zero manual config editing.

## Toggle Switches on Any Surface

- **Desktop App (OpenCode Desktop)**: Click the **UltraCode** pill above the composer for one-click toggles (and to view or clear a queued next milestone in the active session), or open **Settings → UltraCode**.
- **Terminal (TUI)**: Open the Command Palette and search **UltraCode**.
- **Web & Mobile (`ultracode pair`)**: Type `/approvals` or `/direction` in the composer (shows the live `auto` / `manual` state and toggles immediately with zero AI model calls).

- **Command approvals**: Set to `auto` by default so routine steps run smoothly without constant prompts, while explicit deny rules always remain enforced.
- **Direction questions**: Set to `manual` by default so UltraCode asks with structured choice cards whenever a material product or architectural decision needs your input.

## Unified Command Reference

| Command | What It Does |
| --- | --- |
| `ultracode` | Open the terminal UI (all OpenCode flags & subcommands work directly) |
| `ultracode desktop` | Launch OpenCode Desktop, or download the official installer if missing |
| `ultracode pair` | Generate a pairing link & QR code for browser or mobile access |
| `ultracode upgrade` | Update official OpenCode and UltraCode together, then sync |
| `ultracode sync` | Re-sync configuration and managed runtime |
| `ultracode doctor` | Fast setup health check with zero AI model calls |
| `ultracode uninstall --yes` | Cleanly remove UltraCode while preserving your own configs and backups |
