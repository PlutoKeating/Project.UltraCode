UltraCode 的日常控制统一融入终端、桌面应用和手机/网页端，状态实时同步，无需手改任何配置文件。

## 在任意端随时切换双开关

- **桌面端（OpenCode Desktop）**：点击输入框上方的 **UltraCode** 胶囊即可一键切换；也可在 **Settings → UltraCode** 中打开开关页。
- **终端（TUI）**：打开命令面板搜索 **UltraCode** 即可切换。
- **网页端 / 移动端（`ultracode pair`）**：在输入框直接输入 `/approvals` 或 `/direction`（菜单会实时显示当前 `auto` / `manual` 状态，回车秒切，零模型调用）。

- **Command approvals（命令自动执行）**：默认开启（`auto`），自动放行常规操作减少打断；显式禁止的危险规则始终生效。
- **Direction questions（关键方向确认）**：默认开启（`manual`），遇到重大产品或架构分岔时先弹出选择题等你拍板。

## 常用命令速查

| 命令 | 作用 |
| --- | --- |
| `ultracode` | 启动终端界面（所有 OpenCode 参数与子命令直接互通） |
| `ultracode desktop` | 打开官方桌面客户端；若未安装则自动下载官方安装包 |
| `ultracode pair` | 生成连接链接与二维码，接入浏览器或手机客户端 |
| `ultracode upgrade` | 一键更新官方 OpenCode 与 UltraCode 并同步配置 |
| `ultracode sync` | 重新对齐配置与运行时状态 |
| `ultracode doctor` | 零模型调用快速健康体检 |
| `ultracode uninstall --yes` | 干净卸载 UltraCode，完整保留你的个人配置与备份 |
