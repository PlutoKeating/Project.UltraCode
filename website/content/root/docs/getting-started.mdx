**只需两步**：准备一台已安装官方 **OpenCode V2** 的 Linux 或 macOS 机器，花 1 分钟完成安装并跑通你的第一个完整项目。

## 第一步：一条命令安装

```bash
curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash
```

顺手体检确认环境就绪（不消耗模型额度）：

```bash
uc doctor
```

## 第二步：用一句话感受差别

在任意空目录运行 `opencode`，发送下面这句话：

> 请帮我做一个面向独立咖啡馆的极简预约页，支持选择日期、时段和人数，提交后展示预约确认卡片。桌面端和手机端都要排版自然、无重叠。

你很快会注意到与普通 AI 编程完全不同的体验：

1. **先问关键选择题**：不再凭空乱猜，而是把风格与边界问题整理成清晰选项，一次确认。
2. **后台自动分工推进**：规划、写代码、独立复核同步协作，聊天窗口只汇报关键里程碑。
3. **真机浏览器目视验收**：自动拉起真实浏览器点击交互、检查桌面端与手机端截屏，修完错位才说“做完了”。
