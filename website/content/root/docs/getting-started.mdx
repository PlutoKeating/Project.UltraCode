No prerequisites required — if official **OpenCode V2** (including the latest `v2.4+` releases) is not installed yet, the installer sets it up or updates it automatically.

## Step 1: One-Line Install

**macOS / Linux**:

```bash
curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash
```

**Windows (PowerShell)**:

```powershell
irm https://ultracode.plutokeating.beer/install.ps1 | iex
```

Once installed, everything runs through a single command — `ultracode`:

```bash
ultracode           # Open the terminal interface
ultracode desktop   # Open or install the official Desktop app
ultracode pair      # Pair your browser or mobile phone via link / QR
```

## Step 2: Try a Real Goal

Open an empty folder, run `ultracode` (or open Desktop), and send this single sentence:

> Build a clean reservation page for an indie coffee shop where guests pick a date, time slot, and party size, then see a confirmation card. Make sure both desktop and mobile layouts look clean with zero overlap.

What happens differently compared to standard AI chat:

1. **Clarifies upfront with choice cards**: Instead of guessing early, UltraCode groups key style and scope decisions into quick options.
2. **Plans, builds, and reviews in the background**: Specialist roles coordinate behind the scenes while your session stays focused on milestones.
3. **Checks the real UI in Chromium**: It clicks through controls, inspects desktop and mobile views, and fixes layout defects before finishing.
