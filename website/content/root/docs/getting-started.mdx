无需预先折腾环境——如果机器上尚未安装官方 **OpenCode V2**，安装脚本会自动完成安装或升级。

## 第一步：一条命令安装

**macOS / Linux**：

```bash
curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash
```

**Windows（PowerShell）**：

```powershell
irm https://ultracode.plutokeating.beer/install.ps1 | iex
```

装好后你只需记住一个命令 `ultracode`：

```bash
ultracode           # 在当前目录启动终端界面
ultracode desktop   # 打开或自动安装官方桌面客户端
ultracode pair      # 生成二维码与链接，连接手机或网页端
```

## 第二步：用一句话感受差别

在任意空目录运行 `ultracode`（或打开桌面端），发送下面这句话：

> 请帮我做一个面向独立咖啡馆的极简预约页，支持选择日期、时段和人数，提交后展示预约确认卡片。桌面端和手机端都要排版自然、无重叠。

你很快会注意到与普通 AI 对话完全不同的体验：

1. **先问关键选择题**：不再凭空乱猜，而是把风格与边界问题整理成清晰选项，一次确认。
2. **后台自动分工推进**：规划、写代码、独立复核同步协作，界面只汇报关键里程碑。
3. **真机浏览器目视验收**：自动拉起真实浏览器点击交互、检查桌面端与手机端截屏，修完错位才交付。
