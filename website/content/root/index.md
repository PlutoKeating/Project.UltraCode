# UltraCode 教程

UltraCode 为官方 OpenCode 添加长程工程角色、TDD 纪律、全新上下文迭代和独立视觉 QA。它是附加层，不是 OpenCode 分支。

## 你会得到

- 可复用的规划、实现、架构、评审和视觉评审角色。
- Superpowers 提供的需求澄清、TDD 与系统化调试。
- Ralph 驱动的单任务、全新上下文长跑。
- Playwright 驱动的真实浏览器验收。
- 不修改 Provider、Model 或凭据的安装器。

## 推荐路径

1. [快速开始](./getting-started/)：完成一行安装。
2. [安装与卸载](./installation/)：理解文件、依赖和回滚。
3. [工作流](./workflows/)：运行计划、执行和独立评审。
4. [升级与修复](./upgrades/)：在官方升级后同步。
5. [故障排查](./troubleshooting/)：按证据解决问题。

## 非目标

UltraCode 不选择模型、不管理 API Key、不读取 ADC，也不通过真实模型调用来“验证”安装。模型质量与额度由你的 OpenCode 配置决定。
