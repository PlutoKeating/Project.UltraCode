Aucun prérequis : si la version officielle d’**OpenCode V2** (y compris les dernières versions `v2.4+`) n’est pas encore présente, l’installateur l’installe ou la met à jour automatiquement.

## Étape 1 : Installation en une ligne

**macOS / Linux** :

```bash
curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash
```

**Windows (PowerShell)** :

```powershell
irm https://ultracode.plutokeating.beer/install.ps1 | iex
```

Une fois installé, une seule commande suffit au quotidien — `ultracode` :

```bash
ultracode           # Ouvrir l'interface terminal
ultracode desktop   # Lancer ou installer l'application officielle OpenCode Desktop
ultracode pair      # Associer votre navigateur ou mobile via un lien / QR code
```

## Étape 2 : Constater la différence

Ouvrez un dossier vide, lancez `ultracode` (ou `OpenCode Desktop`) et envoyez simplement cette phrase :

> Crée une page de réservation minimaliste pour un café indépendant où les clients choisissent une date, un créneau horaire et le nombre de personnes, puis voient une carte de confirmation. Assure-toi que l’affichage sur ordinateur et sur mobile reste propre, sans aucun chevauchement.

Observez ce qui change par rapport à un chat IA classique :

1. **Clarification initiale par cartes à choix** : au lieu de deviner à l’aveugle, UltraCode regroupe les questions clés de style et de périmètre sous forme d’options rapides.
2. **Planification, implémentation et revue en arrière-plan** : des rôles spécialisés se coordonnent en coulisses pendant que votre session reste centrée sur les jalons.
3. **Vérification de l’interface dans un vrai navigateur Chromium** : il clique sur les contrôles, inspecte les captures d’écran desktop et mobile, et corrige les défauts de mise en page avant de livrer.
