无需预先配置环境——如果机器上尚未安装官方 **OpenCode V2**（全面支持最新 `v2.4+` 版本），安装脚本会自动完成安装或升级。

## 第一步：一条命令安装

**macOS / Linux**：

```bash
curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash
```

**Windows（PowerShell）**：

```powershell
irm https://ultracode.plutokeating.beer/install.ps1 | iex
```

安装完成后，只需使用唯一命令 `ultracode`：

```bash
ultracode           # 在当前目录启动终端界面
ultracode desktop   # 打开或自动下载官方桌面客户端
ultracode pair      # 生成二维码与链接，连接手机或浏览器
```

## 第二步：体验一次完整交付

在任意空目录运行 `ultracode`（或打开桌面端），发送下面这句话：

> 请帮我做一个简洁的独立咖啡馆预约页，支持选择日期、时段和人数，提交后展示预约确认卡片。桌面端和手机端都要排版舒服、无重叠。

你会直接感受到与普通 AI 对话的差异：

1. **先用选择题确认关键取舍**：不急于盲写，而是把风格与范围分歧整理成清晰选项，一次确认。
2. **后台角色分工协作**：调研、设计、实现与独立代码审查在后台协同推进，主对话保持清爽。
3. **打开真实浏览器检查页面**：自动启动 Chromium 点击交互、检查桌面端与手机端画面，修好错位再交付。
