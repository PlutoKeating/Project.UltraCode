## 长任务中的实际使用体验

- **基于真实验证持续推进**：直接自然对话或输入 `/goal <你的目标>`，UltraCode 会先澄清关键取舍，再按阶段稳步推进，并在每项验收标准通过后才宣告完成。
- **随时暂停、继续或插话转向**：发送新消息、使用 `/goal pause` 与 `/goal resume`，或在 **UltraCode** 胶囊中一键暂停/继续/清除；也可随时输入 `/review` 发起独立复核。
- **重启或隔天无缝恢复**：关闭终端或桌面端后重新回来，只需打开 `ultracode` 发送一句：

```text
读取交接并继续
```

UltraCode 会从仓库记录中恢复已完成进度、验证证据与下一步计划，平稳接续剩余工作。
