## 长任务中的实际使用体验

- **自动衔接下一阶段**：每完成一个阶段自动进入下一步，对话中只汇报关键进展、阻塞问题与验证结果。
- **随时插话立即接管**：在任意时刻发送新消息，都会立即调整方向或暂停当前推进，节奏始终由你掌控。
- **重启或隔天无缝恢复**：关闭终端或桌面端后重新回来，只需打开 `ultracode` 发送一句：

```text
读取交接并继续
```

UltraCode 会从仓库记录中恢复已完成进度、验证证据与下一步计划，平稳接续剩余工作。
