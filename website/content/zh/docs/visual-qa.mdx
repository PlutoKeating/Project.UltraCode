## 交付前自动执行的四步检查

1. **启动真实应用**：运行本地服务，在真实 Chromium 浏览器中打开页面。
2. **模拟用户实际操作**：点击按钮、填写表单、切换页面状态，排查控制台报错与交互异常。
3. **检查桌面与手机视口**：核对不同屏幕尺寸下的排版对齐、文字裁剪、元素重叠与色彩对比度。
4. **修复后再复验**：一旦发现视觉或交互缺陷，自动修改代码并重新截图核验，达标后再汇报完成。
