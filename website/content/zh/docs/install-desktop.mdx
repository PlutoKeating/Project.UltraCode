装桌面端只需要两步：**先装 UltraCode，再让它帮你打开桌面窗口。**

<TutorialStep
  step={1}
  title="先在电脑上装好 UltraCode"
  promptLabel="macOS / Linux 打开终端，粘贴这一行"
  promptText="curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash"
  isCommand={true}
  copyLabel="复制"
  copiedLabel="已复制"
  expectLabel="你会看到"
  expectText="最后出现 UltraCode 的版本号和「Ready」，说明装好了。"
>
  Windows 用 PowerShell 粘贴：`irm https://ultracode.plutokeating.beer/install.ps1 | iex`。两种方式都会自动备好官方 OpenCode，不用你先装别的。
</TutorialStep>

<TutorialStep
  step={2}
  title="让它帮你打开桌面窗口"
  promptLabel="在终端里输入"
  promptText="ultracode desktop"
  isCommand={true}
  copyLabel="复制"
  copiedLabel="已复制"
  expectLabel="你会看到"
  expectText="桌面应用自动打开；如果电脑上还没装，它会先下载当前系统的官方安装包再打开。"
>
  装好之后，之后也可以直接从系统的应用列表里打开它，不必每次都敲这一行。
</TutorialStep>

<TutorialStep
  step={3}
  title="第一次打开时，先养熟这三个地方"

  expectText="顶部是标签页，中间是输入框，左下角能选项目。三条都认全了，就可以开始干活。"
>
  桌面窗口和手机、网页看到的是同一套东西，所以你换窗口不用重新学。
