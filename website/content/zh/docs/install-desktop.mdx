大多数人选这一种：**先装好 UltraCode，再加上桌面窗口。** 复制你电脑对应的那一行，粘贴到终端里执行（Windows 用 PowerShell）。

## <span class="uc-step-no">01</span> 装好 UltraCode

<CommandBlock
  title="macOS / Linux"
  command="curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash"
  copyLabel="复制"
  copiedLabel="已复制"
/>

<CommandBlock
  title="Windows"
  command="irm https://ultracode.plutokeating.beer/install.ps1 | iex"
  copyLabel="复制"
  copiedLabel="已复制"
/>

两个框做的是同一件事：准备好官方 OpenCode、UltraCode 本体和运行环境，不需要你先装别的东西。如果当前窗口还认不出 `ultracode`，关掉重开一次终端再继续。

**你会看到**：安装过程会依次更新 OpenCode、安装 UltraCode、完成设置，最后出现版本号和 Ready。

## <span class="uc-step-no">02</span> 把桌面窗口也装上

<CommandBlock
  label="在终端里运行"
  command="ultracode desktop"
  copyLabel="复制"
  copiedLabel="已复制"
/>

第一次运行会下载官方桌面安装包：macOS 和 Windows 会弹出系统安装窗口，按提示点几下完成；Linux 会直接打开。之后从系统应用列表打开也可以。

**你会看到**：桌面应用自动打开；没装过时会先下载当前系统的官方安装包，装过一次以后就是直接启动。

装好之后，从 [桌面端实战](/zh/docs/tutorial-desktop/) 开始第一次任务。只想用终端、不需要桌面窗口？看 [仅终端安装](/zh/docs/install-terminal/)。
