---
title: Long tasks
---

Run `opencode` in your project and describe the audience, outcome and acceptance criteria. You can steer or stop work in the original conversation. The model can delegate, record the next milestone and continue in that session. Long tasks keep the task list, progress and handoff in the repository. After a server restart, ask it to read the handoff and continue.

Search **UltraCode** in the TUI command palette to toggle **Command approvals** (initially auto) and **Direction questions** (initially manual) independently. Auto grants requests the host would otherwise ask about. Explicit deny rules remain effective.
