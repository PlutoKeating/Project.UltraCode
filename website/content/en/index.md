# UltraCode guide

UltraCode adds long-running engineering roles, TDD discipline, fresh-context loops, and independent visual QA to the official OpenCode distribution. It is an additive layer, not a fork.

## What you get

- Reusable planning, implementation, architecture, review, and visual QA roles.
- Brainstorming, TDD, and systematic debugging through Superpowers.
- Single-task, fresh-context iterations through Ralph.
- Real browser acceptance through Playwright.
- An installer that never changes providers, models, or credentials.

## Suggested path

1. [Getting started](./getting-started/) for the one-line install.
2. [Installation](./installation/) for paths, repeatable apply, and removal.
3. [Workflows](./workflows/) for planning and independent review.
4. [Upgrades](./upgrades/) for official OpenCode updates and repair.
5. [Troubleshooting](./troubleshooting/) for evidence-based recovery.

## Non-goals

UltraCode does not select models, manage API keys, read ADC files, or verify installation through real model calls. Model quality and quotas remain part of your own OpenCode setup.
