## 1. Does it modify official OpenCode or read my API keys?

**No.** UltraCode is strictly additive and provider/model-neutral. It never patches the official OpenCode CLI or Desktop app, and never reads, stores, or transmits your API keys.

## 2. Do I need to install OpenCode before installing UltraCode?

**No.** On macOS, Linux, and Windows, both the installer and `ultracode upgrade` automatically detect official OpenCode V2 — installing it from the official channel if missing, or keeping it current if already present.

## 3. Which AI models does it support?

**Whatever model and provider you already use in OpenCode.** UltraCode does not lock you into any model vendor.

## 4. Will it overwrite my existing OpenCode config or skills?

**No.** Install and sync merge cleanly while preserving your own settings and skills. Running `ultracode uninstall --yes` removes only what UltraCode added.

## 5. How do I update or check health?

Run `ultracode upgrade` to update official OpenCode and UltraCode together in one step, or run `ultracode doctor` anytime for a fast check that makes **zero AI model calls**.
