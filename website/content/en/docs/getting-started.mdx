**Just two steps**: all you need is Linux or macOS with official **OpenCode V2** installed.

## Step 1: One-Line Install

```bash
curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash
```

Verify everything is green (zero AI model calls):

```bash
uc doctor
```

## Step 2: Feel the Difference

Open an empty folder, run `opencode`, and send this single sentence:

> Build a minimalist reservation page for an indie coffee shop where guests pick a date, time slot, and party size, then see a confirmation card. Make sure both desktop and mobile layouts look clean with zero overlap.

Watch how different this feels from ordinary AI chat:

1. **Clarifies upfront with choice cards**: Instead of guessing blindly, UltraCode groups key style and scope questions into quick options.
2. **Plans, builds, and reviews in the background**: Specialist roles coordinate behind the scenes while your chat stays focused on milestones.
3. **Opens a real Chromium browser to check its own UI**: It clicks through controls, inspects desktop and mobile screenshots, and fixes layout glitches before saying it is done.
