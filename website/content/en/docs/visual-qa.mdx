## Four Visual Checks Before Calling Work Done

1. **Runs your real app**: Starts the local app and opens it in a real headless browser.
2. **Clicks like a real user**: Exercises buttons, forms, navigation, and interactive states to catch runtime or flow errors.
3. **Inspects desktop & mobile screenshots**: Looks for overlapping elements, clipped text, alignment drift, and contrast issues across screen sizes.
4. **Fixes and re-verifies**: Whenever a visual or interaction defect appears, UltraCode fixes it and captures fresh screenshots before delivering.
