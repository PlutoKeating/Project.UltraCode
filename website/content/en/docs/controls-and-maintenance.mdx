Day-to-day control stays integrated across Terminal, Desktop, and Web/Mobile — live-synced in real time with zero manual config editing.

## Toggle Switches on Any Surface

- **Desktop App (OpenCode Desktop)**: Click the **UltraCode** pill above the composer for one-tap toggles, or open **Settings → UltraCode**.
- **Terminal (TUI)**: Open the Command Palette and search **UltraCode**.
- **Web & Mobile (`ultracode pair`)**: Type `/approvals` or `/direction` in the composer (the `/` menu shows the live `auto` / `manual` status and toggles instantly with zero AI model calls).

- **Command approvals**: Enabled (`auto`) by default so routine steps run without constant prompts, while explicit deny rules always remain enforced.
- **Direction questions**: Enabled (`manual`) by default so UltraCode asks with choice cards whenever a major product or architectural fork needs your call.

## Unified Command Reference

| Command | What It Does |
| --- | --- |
| `ultracode` | Open the terminal UI (all OpenCode flags & subcommands work directly) |
| `ultracode desktop` | Launch OpenCode Desktop, or download the official installer if missing |
| `ultracode pair` | Show a pairing link & QR code for browser or mobile access |
| `ultracode upgrade` | Update official OpenCode and UltraCode together, then sync |
| `ultracode sync` | Re-align configuration and managed runtime |
| `ultracode doctor` | Fast health check with zero AI model calls |
| `ultracode uninstall --yes` | Cleanly remove UltraCode while preserving your own configs and backups |
