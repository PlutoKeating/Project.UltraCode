في تطبيقات الويب والواجهات الرسومية، قد تمر الاختبارات الوحدوية بنجاح رغم وجود أزرار متداخلة، أو تخطيط مكسور على الهاتف، أو تباين نص ضعيف، أو عناصر نقر معطلة.

## أربعة فحوص بصرية قبل اعتبار العمل مكتملاً

1. **تشغيل تطبيقك الفعلي**: يشغّل التطبيق محلياً ويفتحه داخل متصفح حقيقي (Headless).
2. **التفاعل كمستخدم حقيقي**: يجرّب الأزرار والنماذج والتنقل والحالات التفاعلية لكشف أخطاء التشغيل أو انقطاع المسارات.
3. **فحص لقطات شاشة سطح المكتب والهاتف**: يرصد تداخل العناصر، واقتصاص النصوص، وانحراف المحاذاة، وضعف التباين عبر مختلف أحجام الشاشات.
4. **الإصلاح وإعادة التحقق**: كلما ظهر خلل بصري أو تفاعلي، يصلحه UltraCode ويلتقط صوراً جديدة للتحقق قبل التسليم النهائي.
