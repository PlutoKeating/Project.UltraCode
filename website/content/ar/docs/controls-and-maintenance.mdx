يبقى التحكم اليومي متكاملاً عبر الطرفية وتطبيق سطح المكتب والويب/الهاتف — بمزامنة فورية دون أي تعديل يدوي لملفات الإعدادات.

## مفاتيح التبديل على أي واجهة

- **تطبيق سطح المكتب (`OpenCode Desktop`)**: انقر شارة **UltraCode** أعلى مربع الإدخال للتبديل بنقرة واحدة، أو افتح **Settings → UltraCode**.
- **الطرفية (TUI)**: افتح لوحة الأوامر (Command Palette) وابحث عن **UltraCode**.
- **الويب والهاتف (`ultracode pair`)**: اكتب `/approvals` أو `/direction` في مربع الإدخال (تعرض قائمة `/` الحالة الحية `auto` / `manual` وتبدّلها فوراً دون أي استدعاء لنموذج الذكاء الاصطناعي).

- **موافقات الأوامر (`/approvals`)**: مفعّل (`auto`) افتراضياً لتنفيذ الخطوات الروتينية دون مقاطعة مستمرة، مع بقاء قواعد المنع الصريحة سارية دائماً.
- **أسئلة الاتجاه (`/direction`)**: مفعّل (`manual`) افتراضياً ليطرح UltraCode بطاقات اختيار كلما استدعى مسار المنتج أو التصميم المعماري قراراً منك.

## مرجع الأوامر الموحّد

| الأمر | الوظيفة |
| --- | --- |
| `ultracode` | فتح واجهة الطرفية (جميع خيارات وأوامر OpenCode الفرعية تعمل مباشرة) |
| `ultracode desktop` | تشغيل `OpenCode Desktop`، أو تنزيل المثبّت الرسمي إن لم يكن موجوداً |
| `ultracode pair` | عرض رابط ربط ورمز QR للوصول عبر المتصفح أو الهاتف |
| `ultracode upgrade` | تحديث OpenCode الرسمي وUltraCode معاً ثم تنفيذ المزامنة |
| `ultracode sync` | إعادة مواءمة الإعدادات وبيئة التشغيل المُدارة |
| `ultracode doctor` | فحص سريع لسلامة الإعداد دون أي استدعاء لنماذج الذكاء الاصطناعي |
| `ultracode uninstall --yes` | إزالة UltraCode بنظافة تامة مع الحفاظ على إعداداتك الخاصة ونسخك الاحتياطية |
