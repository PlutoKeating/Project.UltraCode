لا حاجة لأي متطلبات مسبقة — إذا لم يكن إصدار **OpenCode V2** الرسمي (بما في ذلك أحدث إصدارات `v2.4+`) مثبتاً بعد، يتولى المثبّت إعداده أو تحديثه تلقائياً.

## الخطوة 1: التثبيت بسطر واحد

**macOS / Linux**:

```bash
curl -fsSL https://ultracode.plutokeating.beer/install.sh | bash
```

**Windows (PowerShell)**:

```powershell
irm https://ultracode.plutokeating.beer/install.ps1 | iex
```

بعد التثبيت، لن تحتاج سوى أمر واحد فقط — `ultracode`:

```bash
ultracode           # فتح واجهة الطرفية
ultracode desktop   # فتح أو تثبيت تطبيق OpenCode Desktop الرسمي
ultracode pair      # ربط المتصفح أو الهاتف عبر رابط أو رمز QR
```

## الخطوة 2: اختبر الفرق عملياً

افتح مجلداً فارغاً، وشغّل `ultracode` (أو افتح `OpenCode Desktop`)، وأرسل هذه الجملة الواحدة:

> أنشئ صفحة حجز بسيطة لمقهى مستقل يختار فيها الضيوف التاريخ والفترة الزمنية وعدد الأشخاص، ثم تظهر لهم بطاقة تأكيد. تأكد من أن التصميم على سطح المكتب والهاتف يبدو أنيقاً ومن دون أي تداخل بين العناصر.

لاحظ كيف تختلف هذه التجربة عن محادثات الذكاء الاصطناعي التقليدية:

1. **يستوضح المتطلبات مسبقاً ببطاقات اختيار**: بدلاً من التخمين العشوائي، يجمع UltraCode أسئلة الأسلوب والنطاق الأساسية في خيارات سريعة وواضحة.
2. **يخطط ويبني ويراجع في الخلفية**: تنسّق الأدوار المتخصصة العمل خلف الكواليس بينما تبقى جلستك مركّزة على المراحل المنجزة.
3. **يفتح متصفح Chromium حقيقياً لفحص الواجهة بنفسه**: ينقر على عناصر التحكم، ويفحص لقطات شاشة سطح المكتب والهاتف، ويصلح عيوب التخطيط قبل التسليم.
